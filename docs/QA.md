## Before sharing a build

- [ ] Walk the whole route manually, from dock to cave; check walls, camera collision, range prompts and golden marker.
- [ ] Inspect every screen at 1366×768 and 1920×1080, including the longest clue/hint and all mock controls.
- [ ] Use only keyboard for movement and all panels; check focus visibility and Tab order.
- [ ] Listen to all four letters on the target laptop; confirm the exact displayed words are narrated.
- [ ] Replay and skip narration; confirm only an explicit skip/reading completion or actual voice completion releases the letter.
- [ ] Disable narration in Settings and complete the adventure using captions alone.
- [ ] Pause during narration and resume; check audio does not overlap a subsequent mock message.
- [ ] Listen to each character's distinct greeting; check the subtitle matches and greetings do not interrupt narration.
- [ ] Adjust voice/music/nature sliders, including zero volume; check the mix on the intended speakers/headphones.
- [ ] Approach, leave and reapproach each NPC; check waving, facing, idle pacing and facial animation.
- [ ] Test Shift sprint, wheel zoom and + / − zoom near buildings; check camera collision and comfort.
- [ ] Solve each chapter and inspect its opening present, fragment number and reward explanation.
- [ ] Start `Resume-Market.cmd` and follow the gold markers across the bridge; verify the recovery shortcut preserves two pieces and does not require replaying earlier chapters.
- [ ] Use pickup/delivery buttons without aiming at a small object; verify distance feedback and step transitions.
- [ ] Open Market overview and press WASD; confirm walking resumes immediately. Verify the Return to walking button in all inspection views.
- [ ] Correct the gear order without clicking the gold key; verify immediate clock animation and reward. Test Check gear order while the arrangement is incorrect.
- [ ] Test Stop from a letter, puzzle, mock panel and pause menu; confirm no late speech/command resumes the game.
- [ ] Leave the game window during each state; confirm focus loss pauses and the previous panel survives.
- [ ] Select each wrong book and route; submit incorrect gears; reset an incorrect temple sequence.
- [ ] Request each hint more than three times; verify level 3 repeats without inventing new content.
- [ ] Inspect journal after each chapter, including replaying an older letter from a later chapter.
- [ ] Test new session from the stopped screen and the ending; verify fresh fragments, hints and checkpoints.
- [ ] Measure frame time on the actual university laptop; target 60 FPS and confirm acceptable 30 FPS minimum under representative load. No target-laptop performance measurement is claimed.
- [ ] Run human pacing tests. The approximate 20-minute target remains unmeasured; no forced timeout is implemented.
- [ ] Export using matching Godot templates; run the exported game offline on a second Windows machine.

Physical robot, Rasa, STT/VAD, production orchestration, live personal questions and experimental humour validation are outside this repository and outside this checklist.
